**Enhancements**

- Theme selection step as removed from onboarding process. Theme can be always changed in Settings. 
- Force selection of model after finished onboarding  
- Automate releases from merge-to-main with per-version notes files. Release workflow now triggers on push to main and only fires when 'releases/X.Y.Z.md' exists for the bumped version. Notes from that file are embedded into both the GitHub release body and latest.json, removing the manual post-publish re-upload step.

**Bug fixes**

- Fix sidebar behaviour when model customize view is open.
- App lock rate-limits unlocks; current credentials required to change/remove the lock or run destructive actions.
- File IO and dialogs moved into Rust; renderer can no longer write to arbitrary paths.
- URL fetcher pins resolved IPs (DNS-rebinding hardening).
- MCP URL/header validation; Modelfile injection guards.
- Tightened Tauri capabilities and CSP; disabled `withGlobalTauri`.
- Patched 4 CVEs; 0 npm audit findings. Streaming parsers cap buffers.
- Per-chat model, system prompt, and parameter overrides now persist.
- DB wipe/restore always re-enables `PRAGMA foreign_keys`; factory reset clears `space_memories`.
- Failed stream startup replaces the empty bubble with a visible error.
- Settings writes revert on failure with a toast. Fixed admin-stream hang race.
- Extracted text capped at 200k chars/file, 500k chars/message; truncation surfaced in chips and inline.
- Unicode-safe HTML stripping and truncation in fetch tool and MCP client.
- Vite 5 → 7, plugin-react 4 → 5. Node floor 20.19+ / 22.12+.
