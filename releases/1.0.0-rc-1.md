**What's new**

- Streaming responses now render via requestAnimationFrame batching, so long outputs stay smooth and the UI no longer stalls on rapid token bursts.
- Network requests use HTTP/2 with gzip and brotli compression, cutting model and tool-call latency on slower connections.
- A read-only SQLite connection pool lets sessions, messages, spaces and snippets load in parallel instead of queuing behind unrelated writes.
- New confirmation dialog replaces native prompts across destructive actions (deleting chats, spaces, snippets, models, API keys).
- Markdown rendering is memoized and inline images lazy-decode, so scrolling long chats stays responsive.
- Keyboard-accessible action menu on your own messages, plus a broader pass on labels, focus rings and screen-reader hints across dialogs, sliders, switches and library views.

**Hardening**

- Tightened SSRF defenses for web fetches and MCP connections, including DNS pinning so a hostname that resolved as public can't be swapped for a private IP mid-request.
- Added per-provider request timeouts and rate limits, and stricter scoping on database reads and space memory writes so a space can no longer accidentally see or touch another's data.
- Fixed a queue dispatch race that could drop or duplicate streamed chunks under load, and surfaced persist failures instead of silently swallowing them.
- Blocking work (file I/O, large JSON imports, hashing) now runs off the main thread, with a hard cap on import paste sizes so a stray multi-megabyte paste can't freeze the renderer.

**Fixes**

- Settings panels no longer re-render the whole tree on every keystroke.
- Memory toggles on a Space now correctly persist a tri-state value, so toggling memory off on one space can't leak through to others.
- The Docs button in Settings → About now opens https://docs.loach.dev instead of sitting inert.
- Various small UI polish across the chat header, models library, spaces and snippets dialogs.
