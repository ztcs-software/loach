**Loach 1.0.0**

The first stable release. Loach is now a native local LLM chat client for Windows and Linux, with first-class support for Ollama and any OpenAI-compatible provider.

**Highlights since the beta cycle**

- Smooth streaming even on long outputs, thanks to requestAnimationFrame batching and a memoized markdown renderer.
- Faster model and tool-call round trips via HTTP/2 with gzip and brotli compression, and a read-only SQLite pool that lets chats, spaces and snippets load in parallel.
- Spaces with scoped memory, attachments and per-space defaults — kept strictly isolated from each other.
- Hardened web fetch and MCP networking with SSRF defenses and DNS pinning, plus per-provider timeouts and rate limits.
- A consistent in-app confirmation dialog across every destructive action, replacing the old native prompts.
- Broad accessibility pass: keyboard-reachable message actions, focus rings, and screen-reader hints across dialogs, sliders, switches and library views.

**Fixes since 1.0.0-rc-1**

- Bumped `rustls-webpki` to 0.103.13 to clear three active-path CVEs in the TLS certificate verification stack.
