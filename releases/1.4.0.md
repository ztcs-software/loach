**What's new**
- **Reworked onboarding.** Setup now sizes its model suggestion against your GPU's VRAM — or system RAM when there's no discrete GPU — and labels every option, so you know what you're in for before the download starts. The pull runs in a strip you can leave working while you carry on. A new tools step covers web fetch and the in-process utilities, opening on a recommended selection with **All OFF / Recommended / All ON** presets and a switch per tool — anything that reaches the network stays off until you turn it on.
- **Better search.** Search now looks inside message content, not just titles. Scope it with the picker or by typing an `in:` filter — `in:chats`, `in:messages`, `in:spaces`, `in:snippets` — and message hits keep a reserved block of their own so a common word can't crowd them out.
- **LaTeX math in replies.** `$$…$$`, `$…$`, `\(…\)`, `\[…\]` and ` ```math ` fences typeset with KaTeX — no setting to hunt for. `$` still works as a currency sign, so "it costs $5 and $10" stays prose. KaTeX ships inside the app and is read from disk only the first time a reply contains math.
- **Auto-lock.** Once an app lock is configured, **Settings → Security** can lock Loach after 1, 5, 15 or 30 minutes without typing, or the moment the window is minimized. Both are opt-in, and `Cmd/Ctrl + Shift + L` locks immediately from anywhere in the app.
- **Storage breakdown.** **Settings → Data** now shows what your chats, attachments and Spaces actually weigh on disk.
- **Undo an archive.** Archiving a chat offers an inline **Undo**, and a quiet **Archived** row appears in the sidebar whenever archived chats exist — so nothing looks gone for good.
- **In-app updates for `.deb` and `.rpm`.** Linux package installs now update in place like the AppImage does, downloading the signed package and elevating through `pkexec`. Installs from v1.2.3 or earlier still need one manual download from the releases page before in-app updates take over.

**Fixes**
- **Correct arithmetic.** The calculator tool moved to a new engine and now groups expressions the way every other language does — `100 / 5 * 2`, `2 * 10 % 4` and `2^3^2` all come out right — and reads scientific notation like `6.022e23` instead of failing on it.
- **Math no longer disturbs code.** Formula detection leaves code blocks, currency and half-typed TeX alone; unparseable TeX shows its own source rather than flashing an error mid-stream.
- **Legible in Light theme.** Contrast failures across toasts, onboarding, code blocks and links are fixed.
- **Reachable by keyboard.** Every control has an accessible name and a visible focus ring.
- **Fewer rough edges.** Timezone-aware date differences, chat parameters that no longer go stale, no leaked streams on cancel, and a model picker that opens in front of the onboarding wizard instead of behind it.
- Dependency updates throughout, including a security fix for the PDF reader.
