**What's new**
- **Agent Skills.** Turn on **Use skills** in **Settings → Skills** and install skills in the open [Agent Skills](https://agentskills.io) format: instructions, reference files and scripts that teach a model a kind of task. The model loads the one that fits your request, or you load one with `/skill`, and it stays in the chat as a chip until you remove it. Skills in `~/.agents/skills`, shared with other agents, show up too. With **Let skills run scripts** on, a skill's own scripts can run, asking you every time.
- **Run scripts.** An opt-in switch in **Settings → Tools** lets the model run Python, bash, Node.js or PowerShell code it writes, or a script from the chat's folder, using what's installed on your computer. Every run shows you the code and the exact command and asks first. A script runs as you, with access to all your files, so it's off by default and never offered in Private Chat.
- **CLAUDE.md and AGENTS.md as project instructions.** A workspace folder without a `LOACHFILE.md` now uses the `CLAUDE.md` or `AGENTS.md` it may already keep for another coding agent, so a project doesn't need a third copy. Turn it off in **Settings → Tools**.
- **Read aloud.** An assistant reply's **…** menu reads it with your system's voices, skipping code blocks and display math.
- **Default context length.** Choose the context window Ollama chats get in **Settings → Features**, or in onboarding. A chat, Space or model with its own setting keeps it.
- **A more honest context bar.** It now counts the tool definitions sent with every message, which can take most of an 8K window when many tools are on. A reply that's cut off says whether the context window filled up or it reached the **Max Tokens** limit.
- **Faster.** Loach starts loading the chat's Ollama model while you type, and the startup preload and memory extraction now match the chat's settings, so Ollama loads the model once instead of reloading it. Long chats open without reading every attachment, settings and MCP tools load without holding up the window, and long sidebar and Library lists draw as you scroll.
- **Smaller touches.** **Move to folder** in a chat's menu. The Send button says why it's disabled, and a chat with no model points you to Models and Providers.

**Fixes**
- **Replies survive a crash.** A reply is saved as it streams, so one cut short by Loach closing, reloading or crashing keeps what had arrived and the tools it ran. **Regenerate** keeps the old reply until the new one starts.
- **Steadier app lock.** When a laptop wakes after idling past its auto-lock time, the first touch now locks Loach instead of restarting the timer, and Loach now locks before it minimizes or hides its window, not after. The docs now say plainly that the lock guards Loach's window, not the database file, which isn't encrypted.
- **Safer backups and erases.** A backup is written through a temporary file, so a failed overwrite keeps the old one. Erasing, a factory reset and an import stop any running reply first, then compact the database so deleted data doesn't linger in the file. Tokens passed to MCP servers as bare arguments are masked in backups, and servers restored with masked values come back switched off and are listed after the import.
- **Clearer approvals.** Approval cards reveal hidden and text-direction characters in tool arguments and file names, instruction files and skills folders always ask before they're changed, and MCP always-allow choices in a backup aren't carried over to servers you haven't approved on this install.
- **Models.** The Models editor keeps quotes and stop sequences intact, models you've deleted are no longer picked for new chats, and `llama3.2` and `llama3.2:latest` count as one model, so a chat no longer loses that model's Thinking and Modelfile defaults.
- **Accessibility and light theme.** Screen readers now hear the slash and `#` palettes and failed unlocks, more controls work from the keyboard, destructive confirmations default to **Cancel**, and muted text and links in the light theme are easier to read.
- Many smaller fixes and hardening throughout.

**Breaking changes**
- **Low VRAM mode is gone.** Ollama dropped its `low_vram` option in 2025 and ignores it, so the switch in **Settings → Features**, the per-chat toggle and the onboarding row did nothing while using newer Ollama versions. To save VRAM, lower the context length, or **GPU Layers** in the Parameters panel's Advanced view.

**Good to know**
- Ollama chats that don't set their own context length now get **16K** instead of 8K, which uses more VRAM. If a model starts spilling out of VRAM or replies slow down, set **Default context length** back to 8K in **Settings → Features**.
